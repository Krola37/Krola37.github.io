Privacy Policy / プライバシーポリシー

Nook (a personal desktop app) · Last updated: 2026-10-29

← Nook

1. Who uses the app / 利用者

Nook is used only by its author, on the author's own PC and with the author's own Google account. It has no accounts, no servers, and no other users.

Nook は、作者本人だけが、自分の PC と自分の Google アカウントで使います。アカウント登録も、Nook 用のサーバーも、ほかの利用者もいません。

2. Google user data accessed / 取得する Google のデータ

  • Google Drive (scope: auth/drive): Nook writes backup copies of its own settings and data into the folder "Program/Nook" in the user's Drive, reads them back when restoring, and reads one spreadsheet in the same Drive. / Nook 自身の設定とデータのバックアップを「Program/Nook」フォルダに書き込み、復元のときに読み、同じ Drive の表計算シート 1 つを読みます。
  • Google Calendar (scopes: auth/calendar.events, auth/calendar.readonly): Nook lists the user's calendars, and adds or deletes events that the user enters or selects in Nook. / カレンダーの一覧を読み、利用者が Nook で入力・選択した予定を追加・削除します。

3. How data is used and stored / 利用と保存

  • The data is used only to provide these features inside Nook. / データは、Nook の上記の機能のためだけに使います。
  • Data is stored on the user's own PC and in the user's own Google Drive. The sign-in token is stored on the PC in an encrypted form (Windows DPAPI). / データは、利用者本人の PC と本人の Google Drive にだけ保存します。ログインのトークンは、PC の中で暗号化して(Windows DPAPI)保存します。
  • Nook does not send Google user data to the author or to any third-party server. / Google のユーザーデータを、作者や第三者のサーバーへ送ることはありません。

4. Sharing / 共有

Google user data is not sold, shared, or transferred to anyone, and is not used for advertising or for training machine-learning models. No human reads the data other than the user.

Google のユーザーデータは、販売・共有・第三者への提供をせず、広告や機械学習の学習にも使いません。利用者本人以外が読むことはありません。

5. Limited Use / 限定的な使用

Nook's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Deleting data and revoking access / データの削除と許可の取り消し

The user can disconnect Google at any time in Nook (Settings → Drive sync → Disconnect) and revoke Nook's access at https://myaccount.google.com/permissions. Backup files in the "Program/Nook" folder can be deleted from Google Drive at any time.

Nook の「設定 → Drive 同期 → 切断」でいつでも接続を切れます。また、上のアドレスで、Nook の許可をいつでも取り消せます。「Program/Nook」フォルダのバックアップは、Google Drive からいつでも削除できます。

7. Changes and contact / 変更・連絡先

This policy may be updated; the date above shows the latest update. Questions: GitHub Issues.
